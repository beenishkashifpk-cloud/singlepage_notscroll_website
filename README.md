# Beenish Kashif — Arrow Navigation CV Portfolio

A responsive single-page CV website presented as four full-screen sections. Normal page scrolling is disabled; use the on-screen arrows, section dots, keyboard arrow keys, Page Up/Page Down, Home/End, or swipe horizontally on touch devices to navigate between sections.

## Run locally
1. Extract the ZIP file.
2. Open `beenish-portfolio/index.html` in a modern browser.
3. Keep the PDF and certificate image in the same folder as `index.html`.

## Files
- `index.html` — all four CV sections
- `style.css` — responsive layout, teal/amber theme, animations and no-scroll presentation
- `script.js` — arrow/dot/keyboard/touch navigation and rotating skill labels
- `Beenish_BSCS_Resume.pdf` — downloadable CV
- `google-coursera-certificate.png` — certificate preview
- `favicon.svg` — browser icon

The design respects `prefers-reduced-motion`. External fonts and JavaScript libraries are not required.
